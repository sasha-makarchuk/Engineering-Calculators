Theory & Calculation Methodology (AWS / Shigley Method)

This application implements the Unit Line Weld Method established by Omer Blodgett and standardized in Shigley’s Mechanical Engineering Design and the AWS/AISC structural design codes. The method simplifies 3D weld group evaluation by treating welds as 1D lines and scaling properties by the minimum throat size.

1. Effective Throat & Unit Properties

For standard 45° fillet welds with leg size h, the effective throat size t is defined as:

t = 0.7071 · h

Area and second moment of area properties are calculated as line elements (Au, Iux, Iuy, Ju) and multiplied by throat thickness t:

A = t · Au,    Ix = t · Iux,    Iy = t · Iuy,    J = t · Ju

2. Centroidal Moment Resolution

All applied force vectors F = (Fx, Fy, Fz) applied at location (xp, yp, zp) are translated to the centroid of the weld group (x̄, ȳ, 0). The total net moments are resolved as:

Mx = Mx,ext + (yp - ȳ)Fz - zpFy    (Bending about X)
My = My,ext + zpFx - (xp - x̄)Fz    (Bending about Y)
Mz = Mz,ext + (xp - x̄)Fy - (yp - ȳ)Fx    (Torsion about Z)

3. Stress Vector Components at Hotspot Points

At any evaluation point (x, y) with relative distance rx = x - x̄ and ry = y - ȳ, shear stress components are resolved in 3D orthogonal directions:

  • Direct Primary Shear (In-Plane & Out-of-Plane):
    τ'x = Fx / A,    τ'y = Fy / A,    τ'z = Fz / A
  • In-Plane Secondary Shear (Torsion Mz):
    τ''t,x = - (Mz · ry) / J,    τ''t,y = (Mz · rx) / J
  • Out-of-Plane Throat Shear (Bending Mx, My):
    τ''b,z = (Mx · ry) / Ix - (My · rx) / Iy

4. Combined Vector Resultant Stress & Allowables

The total shear stress vector magnitude on the throat plane is calculated by taking the Euclidean vector norm of all components:

τx = τ'x + τ''t,x
τy = τ'y + τ''t,y
τz = τ'z + τ''b,z
τmax = √( τx² + τy² + τz² )

Per AISC and AWS specifications, allowable shear stress for weld metal (based on electrode ultimate tensile strength Sut) is given by:

τallow = 0.30 · Sut      n (Factor of Safety) = τallow / τmax
